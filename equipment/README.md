# equipment/ — 장비 어휘

`places/` 와 **같은 자리의 파일**이다. 장소가 `places.json` 으로 그라운딩되듯 장비는
여기로 그라운딩된다.

| | 장소 | 장비 |
|---|---|---|
| 계약 | `contracts/place.schema.json` | `contracts/equipment.schema.json` |
| 데이터 | `places/places.json` | `equipment/equipment.json` |
| 추출 | `npm run extract:places` | `npm run extract:equipment` |
| 원천 | Unity 씬 | 목 게이트웨이 레지스트리 + 정답셋 |

## 왜 만들었나 — 6단계가 대조를 하나 남겼다

260906 실측(`reports/2026-09-06_마일스톤분리_6단계.md` §4 축 3)에서 이렇게 갈렸다.

| 어휘 축 | 목록을 줬나 | Qwen3 8B | EXAONE 7.8B | Qwen3 4B |
|---|---|---|---|---|
| 장소 | **줬다** | **0** | **0** | **0** |
| 장비 | **안 줬다** | 22% | 48% | 5% |

같은 모델·같은 프롬프트·같은 디코딩·**같은 응답 안**에서 갈린 것이 하나뿐이다.
그래서 장비에도 같은 처방을 준다. 지어낸 이름은 `system-01`·`control-01` 처럼
**그럴듯한** 것들이었다 — 모델이 못 하는 것이 아니라 고를 목록이 없었던 것이다.

## 원천이 둘인 이유 — 정답셋만 쓰면 축이 자기 자신을 채점한다

채점기(`score-generation.mjs` 축 2d)의 장비 어휘는 **정답셋의 `assigned_targets`
합집합**이다. 그것만 프롬프트에 실으면 「목록에서 고를 줄 아는가」가 아니라
**「준 것을 옮겨 적는가」**를 재게 된다. 오답 선택지가 없는 시험이다.

그래서 목 게이트웨이 레지스트리의 장비를 합집합으로 넣는다. 레지스트리에만 있는 장비가
곧 오답 선택지다.

```
프롬프트에 주는 목록  ⊋  채점 어휘
        10건              4건        오답 선택지 6건
```

**`verify:no-leak` 5번이 이 관계를 검사한다.** 같아지면 실패이고, 정답의 장비가 목록에서
빠져도 실패다(「정답을 쓰지 말라」고 말한 셈이 된다).

## 지금 상태

장비 **10건** — 레지스트리 10 · 정답셋 4(전부 레지스트리에 있다) · 오답 선택지 6.
종류 5종(`actuator`·`camera`·`edge_node`·`robot`·`sensor`).

`npm run extract:equipment` 로 다시 뽑는다. **손으로 고치지 마라** — 원천은
레지스트리와 정답셋이다.

## 레지스트리를 복사하지 않는다

`gateway/hub.ts` 와 `stt/vocab.py` 가 같은 `registry.json` 을 읽는다. 복사본을 두면
화면의 장치 목록·음성 인식 어휘·생성 어휘가 조용히 갈라진다. 경로는
`VIZ_REGISTRY_DIR` 로 바꾼다 — `hub.ts` 와 같은 환경변수다.

## 채울 때 지켜야 하는 것

- **손으로 고르지 않는다.** 레지스트리의 `entities[]` 를 통째로 옮긴다. 「이건 임무
  대상이 아닌 것 같다」로 빼기 시작하면 목록이 사람의 판단에 기대게 된다
  (`extract-places.mjs` 가 문을 좌표로 가르고 이름으로 안 가른 것과 같은 이유다).
- **이름을 지어내지 않는다.** 레지스트리에 없는 식별자는 `label`·`kind` 가 `null` 이다.
  `places.json` 의 자리표시와 같은 원칙이다 — 없는 것은 없는 대로 둔다.
- **기종을 싣지 않는다.** 옛 대본의 `hardware[]` 에는 이름이 있지만 그 값은 「Unitree
  Go1」 같은 **기종**이고, 프롬프트 규칙 4가 금지하는 바로 그것이다. 실으면 모델에게
  금지어를 쥐여 주는 꼴이 된다.
- **출처를 모델에게 보이지 않는다.** `render_equipment()` 는 `equipment_id`·`label`·
  `kind`·`aliases` 넷만 편다. 어느 장비가 정답셋에서 왔는지가 새면 그것이 정답 누출이다.
- **`kind` 는 enum 이 아니다.** 장소의 종류는 추출기가 스스로 정하지만 장비의 종류는
  남의 파일(`registry.json` 의 `entity_type`)이 정한다. enum 으로 박으면 레지스트리에
  종류가 하나 늘 때 두 벌이 조용히 갈라진다.

## 415 편이 돌아오면

`e2c3f0f` 가 4층 미측정을 이유로 `MSN-260826-01` 을 정답셋에서 들어냈다. 4층을 재고
그 편이 돌아오면 `go1-02`·`arm-03`·`cam-4f`·`cam-5f` 가 채점 어휘에 함께 돌아오고,
그 넷은 레지스트리에 없다. 추출기는 그때 **식별자만 싣고 이름은 `null` 로** 둔다 —
그 자리는 지금 비어 있어도 열어 두었다.
